# Memora Memory Synthesis Engine

Companion-Led Memory Harvesting + Visual Life Journal

- LANE 27S-E - Home Memory Atrium V1 Build
- Next stage: Home Stage 4 - Motion / Snap Feel / Spacing / Visual Hierarchy Tuning

## 2. Core Idea

Memora should help users remember their lives by gently harvesting daily details through conversation, capture, recap, and reflection, then synthesizing those details into useful memory artifacts.

The engine turns scattered moments into a living personal memory system.

## 3. Product Vision Statement

Memora becomes a companion that helps people notice, preserve, understand, and revisit the small details of their lives.

Instead of asking users to maintain a rigid journal, Memora learns how to ask the right gentle questions, identify emotionally meaningful moments, and turn daily fragments into a visual life journal.

## 4. Problem This Solves

People forget important ordinary details:
- what happened today
- what someone said
- what they felt
- what they learned
- what changed
- what needs follow-up
- what patterns are forming over time

Traditional journaling requires effort and consistency. Generic notes become clutter. Chat histories disappear into scrollback. Photos lack context. The Memory Synthesis Engine helps transform all of those fragments into structured, emotionally useful memory.

## 5. Core Feature Components

### Companion-Led Memory Harvesting

Memora asks lightweight, human-feeling questions that help users recall useful details without making journaling feel like homework.

### Adaptive Companion Memory Model

Memora should learn safe, user-approved patterns about what the user tends to care about: people, places, projects, goals, routines, emotional themes, recurring obligations, and relationships between memories.

### Daily Memory Intake System

Daily intake can come from MeMChat conversation, Quick Capture, voice/text capture, Daily Recap, journal entries, tagged memories, and user-selected photos or artifacts in future lanes.

### Daily Memory Synthesis

The engine distills daily intake into key events, emotional tone, people/entities mentioned, follow-ups, unresolved items, highlights, lessons, and memory anchors.

### Memory Artifact Generation

Generated artifacts may include daily chapters, visual memory cards, recap journal pages, weekly memory digests, timeline entries, storybook pages, and future reel/movie/memory cinema artifacts.

### Review / Recall / Reinforcement

Memora should help users revisit memories through gentle recall prompts, daily/weekly recap, archive search, spaced memory reinforcement, emotionally meaningful resurfacing, and games or reflection loops where appropriate.

## 6. End-to-End Flow

1. User captures a thought, moment, voice note, message, or daily reflection.
2. Memora asks a small clarifying question if helpful.
3. The system extracts safe structured memory metadata.
4. Daily synthesis creates a short chapter from the fragments.
5. The user reviews, edits, approves, or dismisses the synthesis.
6. Approved memory artifacts enter the archive/journal.
7. Future Memora interactions can recall approved memory context.
8. Visual artifacts may become part of a storybook, timeline, or memory cinema.

## 7. Feature Ladder

### Phase A - Companion Reflection Layer

Memora asks better follow-up questions and helps users reflect in MeMChat/Daily Recap.

### Phase B - Daily Synthesis

Daily inputs are summarized into a useful, editable memory chapter.

### Phase C - Daily Visual Memory

Approved daily chapters can generate or attach a visual memory card.

### Phase D - Visual Journal / Storybook

Memories become a browsable, beautiful life journal with days, chapters, people, themes, and visual artifacts.

### Phase E - Reel / Movie / Memory Cinema

Important periods can become cinematic recaps, reels, or guided memory movies.

## 8. Premium / Monetization Direction

Premium value can come from richer synthesis history, longer memory retention, more visual artifact generation, storybook/export features, memory cinema/reel generation, advanced archive search, deeper companion personalization, and family/life-event collections if privacy rules allow.

Premium must feel like expanded memory care, not paywalled emotional manipulation.

## 9. Privacy and Safety Guardrails

- User control and review matter.
- Sensitive memories should not be surfaced carelessly.
- Memory extraction should prefer explicit user-approved context.
- Users need edit/delete controls.
- Avoid pretending certainty about memories that were inferred.
- Mark inferred or low-confidence synthesis clearly.
- Do not expose private memory content in analytics, logs, screenshots, or external prompts unless the user explicitly approves.
- Future AI memory behavior needs clear boundaries, retention rules, and deletion behavior.

## 10. Non-Goals

- Not the immediate Home Stage 4 coding lane.
- Not a full autonomous diary that writes unreviewed personal truth.
- Not a therapist replacement.
- Not a surveillance system.
- Not a social feed.
- Not an excuse to wire unapproved private data sources.
- Not a reason to redesign MeMChat internals during the active Home lane.
